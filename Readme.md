# Cloud Resource Intelligence Platform (CRIP)

An ML-powered platform for cloud cost anomaly detection,
workload-level cost attribution, and cloud resource intelligence.

## Problem

Cloud costs can increase unexpectedly, while it is difficult to
identify which workloads or resources caused the increase.

## Goals

- Detect abnormal cloud spending
- Attribute costs to workloads/resources
- Correlate cost with infrastructure metrics
- Explain potential causes of cost anomalies
- Provide actionable recommendations
